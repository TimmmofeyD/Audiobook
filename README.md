# 🎙️ Студия нейроозвучки книг

Полный цикл: импорт книги (EPUB/FB2/TXT) → анализ персонажей и говорящих →
исследование лора на вики → уникальные голоса ElevenLabs → режиссура каждой
реплики → синтез → контроль качества → экспорт MP3/M4B/WAV.

## ✨ Возможности

| Этап | Что делает |
|---|---|
| **Импорт** | EPUB / FB2 / TXT → главы, сцены, реплики |
| **Анализ** | LLM находит персонажей, распределяет реплики, пол/возраст/роль, алиасы |
| **Вики-исследование** | Обогащает персонажей каноном с Fandom-вики + возрастная группа |
| **Кастинг** | 3 кандидата голоса на персонажа, прослушивание, закрепление (LOCK) |
| **Режиссура** | Уникальная подача и эмоции для каждой реплики, без шаблонов |
| **QC** | Акустика + ASR (Scribe) + ручное утверждение |
| **Генерация** | Превью сцен, аудио глав, повторы, паузы |
| **Экспорт** | MP3 (по главам), M4B (единая книга), WAV (мастер) |

## 🚀 Быстрый старт

```powershell
# 1. Окружение и зависимости
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 2. Ключи
copy .env.example .env
# открой .env: впиши ELEVENLABS_API_KEY, при желании LLM_*

# 3. Запуск
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открой **http://127.0.0.1:8000**

> ⚠️ ElevenLabs блокирует часть регионов: если API редиректит на страницы помощи — включи VPN.

## 📚 Пайплайн в один клик

Кнопка **«Аудио-пайплайн»** выполняет всю цепочку автоматически:

1. Анализ всех глав → все персонажи собираются в общий Character Bible
2. Вики-исследование каждого персонажа → канон, возраст, портрет голоса
3. Режиссура сцен → уникальные эмоции на каждую реплику
4. Кастинг голосов → 3 кандидата на персонажа
5. Синтез целевых глав → превью → аудио

Или через API:

```http
POST /api/books/{book_id}/pipeline   {"chapter_id": "<id-главы>"}
```

## 🖥️ Разделы интерфейса

- **Обзор книги** — статистика, структура, кнопка «Анализ» у каждой главы
- **Сценарий** — реплики, назначение говорящих, редактор режиссуры
- **Персонажи** — карточки Character Bible
- **Кастинг голосов** — описание голоса + «Вики: персонаж» + 3 кандидата
- **Генерация** — очередь с прогрессом/ETA, готовность по главам
- **Контроль качества** — прослушивание, сравнение A/B, утверждение
- **Экспорт** — сборка M4B/MP3/WAV

## 🛠️ Основное API

| Метод | Эндпоинт | Назначение |
|---|---|---|
| POST | `/api/books` | Загрузить книгу |
| DELETE | `/api/books/{id}` | Удалить книгу (данные; схема БД остаётся) |
| POST | `/api/books/{id}/analyze` | Анализ всей книги |
| POST | `/api/chapters/{id}/analyze` | Анализ одной главы |
| POST | `/api/characters/{id}/research` | Обогащение из вики |
| POST | `/api/characters/{id}/voice-candidates` | 3 кандидата голоса |
| POST | `/api/characters/{id}/voice-lock` | Закрепить голос |
| POST | `/api/scenes/{id}/direct` | Режиссура сцены |
| POST | `/api/scenes/{id}/generate-preview` | Превью сцены |
| POST | `/api/books/{id}/generate` | Озвучка книги |
| POST | `/api/books/{id}/export` | Экспорт M4B/MP3/WAV |
| GET | `/api/jobs/{id}` | Статус/прогресс/ETA задачи |

## 🔐 Безопасность

- Ключи только в `.env`; `.env` в `.gitignore` и не коммитится.
- `.env.example` поставляется с пустыми ключами.
- Ответ LLM недоверенный: JSON-контракт + строгая валидация + fail-closed.
- SSML запрещён; аудиотеги только из белого списка.
- Ответы провайдера не попадают в логи с ключами.
