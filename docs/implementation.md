# Статус реализации по ТЗ v2

Эта поставка — локальная первая версия с полноценным рабочим процессом. Она объединяет основные пользовательские функции MVP-0–MVP-4, но не является завершённой production-реализацией всех требований документа.

## Реализовано

| Область | Что работает |
| --- | --- |
| Импорт | TXT/FB2/EPUB; чтение EPUB по spine, вложенные главы FB2, абзацы и исходные тексты, UUID, сегментация длинных реплик |
| Защита парсера | Ограничения объёма/распаковки, отказ от внешних XML entities, zip path traversal, отсутствие сетевой загрузки из книг |
| Анализ | Опциональный LLM по сценам, JSON mode с локальной строгой валидацией, персонажи/aliases/evidence/confidence, summaries/events, ручной путь UNKNOWN |
| Character Bible | Постоянные ID, редактирование, сохранение ручных решений и LOCK при повторном анализе |
| Кастинг | Voice Design v3, три аудиопробы, существующий voice_id, сохранение выбранного голоса, provenance, LOCK и история замен |
| Режиссура | LLM-планы и ручные override, раздельные внутренние/выраженные эмоции, intent, delivery, allow-list тегов, паузы |
| Произношение | Одобренные контекстные замены конкретной реплики с версией; границы слов, сохранение оригинала |
| Озвучка | Eleven v3 single и Text-to-Dialogue, Multilingual v2 для narration, конфигурируемые лимиты и голосовые ID |
| Трассировка | Все utterance_ids, исходные версии, provider/model/voice IDs, фактический payload, seed, prompt version, attempt, request ID, аудиофайл, QC |
| Кэш | Повторное использование активных и совместимых сохранённых блоков; approved artifacts не генерируются заново без изменения/запроса |
| Возобновление | SQLite-очередь, восстановление RUNNING, контрольная точка аудио до QC, повтор failed jobs, приоритет ручной регенерации |
| QC | Акустические peak/RMS/clipping/silence/duration; live ASR Scribe, WER/CER; ограниченные повторные попытки, сохранение истории и ручное утверждение |
| Монтаж | Действительные WAV-мастеры, MP3-главы и M4B с chapter markers; точные межблочные паузы, постоянное усиление главы с учётом true peak |
| UI | Восемь разделов на русском, редактор реплик, история A/B, очередь, QC, скачивание экспорта |

## Частично реализовано или оставлено следующему этапу

- **Хранилище production:** SQLite и локальные файлы заменяют PostgreSQL, S3/MinIO и Redis для первого запуска. Нет распределённых locks, нескольких workers, пользователей, квот, автоматических backup и аутентификации. Нельзя публиковать этот локальный сервер в интернет как готовый сервис.
- **Speaker identity:** реальный embedding/encoder и проверка похожести голосов при кастинге не подключены. Численные similarity не выдумываются; QC требует ручного прослушивания.
- **Агенты:** анализ/attribution/continuity объединены в валидируемый LLM pipeline, кастинг опирается на редактируемый voice brief. Нет отдельного второго LLM-pass для диапазона 0.70–0.89, автоматического audition scoring и полноценного графа отношений/временных состояний. Средняя уверенность консервативно отправляется на ручную проверку.
- **Pronunciation Agent:** контекстный ручной словарь работает; автоматическая морфология чисел/дат, IPA и разрешение омографов агентом ещё не реализованы.
- **Retry policy:** bounded retry с новым seed и последующим снятием тегов. Автоматическое дробление на четвёртой попытке, отдельный Quality Review Agent и смена backend с проверкой voice identity ещё не реализованы. FAILED jobs остаются доступными для ручного повторения.
- **Монтаж:** FFmpeg собирает выбранные артефакты без лишнего TTS. При повторном экспорте главы пересобираются целиком; отдельного кэша только затронутой главы пока нет. WAV — мастер, FLAC и обложка M4B пока не добавлены. Точный монтаж внутри одного dialogue artifact потребует time alignment.
- **Метрики:** есть requests/characters/duration/retries и причины QC. Денежная стоимость не оценивается без достоверного тарифа; история provider metadata сохраняет доступные character-cost. Распределённая телеметрия и панели production отсутствуют.
- **Качество речи:** live-контракты проверены MockTransport и официальной документацией, но реальный ключ не предоставлялся. Приёмка качества на 10–15 минутах, A/B narration, speaker accuracy/MOS и тест целой книги остаются обязательными перед эксплуатацией.
- **Входные форматы:** текстовые книги без DRM, корректный XML/XHTML. OCR сканов и восстановление повреждённых EPUB не входят в эту поставку.

## Критерии приёмки

Критерии 1–9, 11–14 из ТЗ имеют работающую локальную реализацию с указанными границами. Критерий 10 реализован как ASR comparison и bounded retry, проверен на моках, требует живого прослушивания с ElevenLabs. Автоматическая проверка идентичности голоса и полная production-инфраструктура не считаются выполненными.

Тестовые демонстрационные тоны предназначены только для проверки software workflow. Они не являются доказательством качества русской нейроозвучки.

## Проверенные контракты провайдера

- [Voice Design API](https://elevenlabs.io/docs/api-reference/text-to-voice/design): `eleven_ttv_v3`, текст 100–1000 символов.
- [Create voice API](https://elevenlabs.io/docs/api-reference/text-to-voice/create): сохранение выбранного generated_voice_id.
- [Text-to-Dialogue API](https://elevenlabs.io/docs/api-reference/text-to-dialogue/convert): Eleven v3, configured safe limit 2000 символов с тегами и до 10 voice_id.
- [Text-to-Speech API](https://elevenlabs.io/docs/api-reference/text-to-speech/convert): single TTS.
- [Speech-to-Text API](https://elevenlabs.io/docs/api-reference/speech-to-text/convert): Scribe ASR.
- [Structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs): контракт совместимого LLM-клиента. Здесь применяется JSON mode и локальная валидация, а не обещание provider-side strict schema для всех совместимых серверов.

Дата проверки API в конфигурации: 19 сентября 2026. Доступность моделей и возможности аккаунта следует проверять при первом live-запуске.
