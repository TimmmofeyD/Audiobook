# Internal service contracts

Python 3.12, FastAPI application, SQLite persistence via root-owned repository, vanilla browser UI. Services take plain dictionaries and return plain dictionaries. All IDs are UUID strings. File paths are pathlib.Path or absolute strings. UTF-8 throughout. Services do not access DB: orchestration owns persistence. Shared configuration is root-owned app/config.py; pass dependencies into constructors.

## Parsed book / analysis (agent-owned)

`app/parsers/books.py`: `parse_book(content: bytes, filename: str) -> dict` returns `{title, author, language:'ru', chapters:[{title, scenes:[{paragraphs:[{text, utterances:[{source_text, spoken_text, type:'NARRATOR'|'UNKNOWN', speaker_confidence:float}]}]}]}]}`. Parser includes EVERY source paragraph in document reading order. IDs assigned by orchestrator. TXT, FB2, EPUB; reject oversized/unsafe archives and unsupported input. No network parsing.

`app/agents/pipeline.py`: `AnalysisPipeline(base_url='', api_key='', model='', mode='manual')`; async `analyze(book:dict, characters:list, scenes:list) -> dict` returns `{characters:[{id(optional existing), canonical_name, aliases:[], gender:{value,confidence}, age_band:{value,confidence}, role, baseline_traits:[], speech_profile:{}, evidence:[]}], attributions:[{utterance_id, character_name (must match returned/existing canonical_name) or null, confidence, evidence:[], reason_code}], scene_summaries:[{scene_id,summary}], events:[], mode:'llm'|'manual'}`. scenes have id, title, utterances (id, source_text, spoken_text, type). Narrator exists and is canonical_name 'Рассказчик'. Offline path keeps uncertain dialogue UNKNOWN. LLM data validation must fail closed on unsupported character IDs/names, references, or malformed data. async `direct(scene:dict, characters:list) -> list[dict]`: each item `{utterance_id, intent, emotion_internal:{}, emotion_expressed:{}, delivery, audio_tags:[], pause_before_ms:0, pause_after_ms:350}`; do not rewrite text or assign voices. Include prompts version constants/files and tests. No DB imports.

## TTS / QC / audio (agent-owned)

`app/providers/base.py`: ProviderError(message, retryable=False, retry_after=None); `AudioArtifact` dataclass `audio:bytes, extension:str, model_id:str, parameters:dict, request_id:str|None=None`; `VoiceCandidate` dictionary `{generated_voice_id, audio_base64, media_type, duration_secs, description}`. `ElevenLabsAdapter(api_key: str, limits_path:Path|None=None)` async `design_voice(brief:dict,audition_text:str)->list[dict]`; async `save_voice(generated_voice_id:str,name:str,description:str)->dict` returning `{voice_id,...}`; async `synthesize_single(text:str,voice_id:str,performance:dict,seed:int,model_id:str='eleven_v3')->AudioArtifact`; async `synthesize_dialogue(lines:list[dict],seed:int)->AudioArtifact` each line `{text,voice_id,performance}`; async `get_voice_metadata(voice_id:str)->dict`; async `healthcheck()->dict`; async `transcribe(audio:bytes,filename:str)->str` if available. `DemoAdapter` same, returns obviously demo WAV tone (no false speech), voice IDs 'demo-...'. Can provide preview candidate audio as WAV. Output extension without dot.

`app/services/audio.py`: `AudioEngine(ffmpeg_path:str='')`; sync `inspect(path:Path)->dict` acoustic checks/duration/peak/silence flags, no fake speaker metrics; `export(chapters:list[dict],output_dir:Path,title:str,author:str,formats:list[str])->dict` chapters `{id,title,segments:[{path, pause_before_ms, pause_after_ms}]}` returning `{files:[{path,filename,format,chapter_id(optional)}]}`; produce WAV masters and requested mp3/m4b via FFmpeg with metadata/chapter markers. If unavailable, explicit failure. Sync `qc_text(expected:str,actual:str)->dict` WER/CER; `evaluate_qc(acoustic:dict,text_metrics:dict|None=None,speaker_metrics:dict|None=None,demo:bool=False)->dict` returns `{status:'PASS'|'REVIEW'|'FAIL',issues:[],metrics:{}}`. Missing ASR or speaker identity => REVIEW (manual approval possible), demo => REVIEW. Expose any planner helpers separately; no database imports. Own config/provider_limits.json, tests test_provider.py/test_audio.py.

## API and UI (root-owned API; UI agent static files)

All endpoints prefixed `/api`. Errors `{detail: string}`. GET `/config` gives `{mode:'demo'|'live',llm_configured,tts_configured,version,limits:{dialogue_chars:2000},...}`. GET `/books` array, POST `/books` multipart file (optional title/author), POST `/demo` creates demo book, GET `/books/{id}` complete object described below. POST `/books/{id}/analyze` => job. PATCH `/books/{id}` `{title?,author?}`.

Book detail `{id,title,author,status,created_at,source_name,language,characters:[],chapters:[{id,title,position,scenes:[{id,title,position,summary,preview_approved,utterances:[]}]}],jobs:[],exports:[],metrics:{total_utterances,ready_utterances,review_utterances,total_characters,generated_characters,tts_requests,audio_seconds}}`. Character `{id,canonical_name,aliases,gender,age_band,role,baseline_traits,speech_profile,evidence,voice_brief,voice:{voice_id,provider,status:'LOCKED',provenance,version}|null,candidates:[]}`. Utterance `{id,scene_id,source_text,spoken_text,type,speaker_id|null,speaker_confidence,review_required,performance:{...},status,audio_url|null,generation_id|null,qc:{status,issues,metrics}|null}`. Job `{id,kind,status:'QUEUED'|'RUNNING'|'COMPLETED'|'FAILED',progress:0..1,message,error,created_at}`. Exports `{id,filename,format,url}`.

POST `/books/{id}/characters` `{canonical_name}`. PATCH `/characters/{id}` editable basic fields (aliases array, gender/age_band {value,confidence}, role, voice_brief dict). POST `/characters/{id}/voice-candidates` `{voice_brief?:dict,audition_text?:str}` => job. POST `/characters/{id}/voice-lock` `{generated_voice_id?:str,voice_id?:str,provenance:'designed'|'library'|'licensed'|'consented_clone',audition_confirmed:true}` => character; replacing LOCK requires `{replace:true, regeneration_scope:'all'}` invalidates old generation selection and previews (keeps history); response 409 if no explicit replacement. UI must make this explicit. Candidate objects have generated_voice_id, audio_url, description.

PATCH `/utterances/{id}` `{speaker_id?,spoken_text?,type?,performance?:{intent,emotion_internal,emotion_expressed,delivery,audio_tags,pause_before_ms,pause_after_ms},mode?:'auto'|'single'|'dialogue'}`. Original immutable. POST `/scenes/{id}/direct` => job. POST `/scenes/{id}/generate-preview` => job. POST `/scenes/{id}/approve-preview` `{approved:true}` => scene; only after audio exists. POST `/books/{id}/generate` `{}` => job (requires locks, resolved speakers, at least one approved preview). POST `/utterances/{id}/regenerate`, POST `/scenes/{id}/regenerate`, POST `/chapters/{id}/regenerate` => job. POST `/generations/{id}/approve` `{approved:true}` approve QC manually. GET `/generations/{id}` full record. GET `/jobs/{id}`, POST `/jobs/{id}/retry`.

POST `/books/{id}/export` `{formats:['mp3','m4b','wav']}` => job; requires all active generations QC approved. GET `/books/{id}/pronunciations` array; POST `/books/{id}/pronunciations` `{lexical_form,spoken_form,context_signature (specific utterance ID REQUIRED),approved:true}`; DELETE `/pronunciations/{id}`. Audio served `/api/files/{opaque path}`; URLs provided by server, never construct disk paths. UI polls detail when jobs run. No key storage/browser provider calls. Basic settings display server env configuration, not secret input. Clear demo banner.
